## The headline

We built the showcase around **4 interior rooms** (living, kitchen, bath, bedroom).
The actual listing is a **multi-level Costa Blanca townhouse** whose value is mostly
**outdoors and mostly un-modelled**: a **2nd-floor covered balcony** and a **3rd-floor
solarium** (two outdoor co-heroes), a ground-floor covered terrace, front + side terraces,
plus the shared **community garden and pool** — and **5–7 bedrooms** and 2 bathrooms inside. In this market, outdoor living _is_ the
aspiration, so this is exactly where "show the potential" has the most upside — and
several of these spaces are currently near-bare, i.e. maximum before→after delta.

Two consequences:

1. **We need to _understand_ a property, not just restage given rooms.** 31 unlabeled
   photos → we must first classify what each space is (and dedupe angles) before we
   can stage it. That's a new pipeline stage, and it's the real "scope/understanding"
   increase.
2. **Outdoor staging needs its own prompts _and_ a sharper honesty line** — the
   difference between _dressing_ a space (honest potential) and _building_ something
   (a capital improvement that must be labelled, never implied).

## "Show the potential" per space — and the honesty boundary

The interior rule ("restyle, never restructure") is only half the story outdoors. We
need three honesty tiers:

1. **Restyle — honest potential (present as "the potential").**
   Furniture, soft furnishings, planters, pergola dressing (drapes/blinds), lighting,
   surface finish/paint, landscaping of _existing_ beds and lawn. This is "dress the
   space you already have." Same gate as interiors.

2. **Capital improvement — only if feasible, and always labelled "potential upgrade /
   subject to works", never shown as existing.** Adding a pool, building or glazing a
   structure, extending, adding plumbing. These change what physically exists in a way a
   buyer can't just furnish. The gate must first ask _is it even feasible?_ — for
   **Zeniamar the answer is no** (no room for a pool), so none is shown. Where it is
   feasible elsewhere it needs its own badge and copy ("Imagine a plunge pool here — a
   possible addition"), never an implied-existing render.

3. **Shared amenity — real, enhance context only.** The community pool exists; showing
   it beautifully / with lifestyle is fair. Never imply it's private.

This "**restyle vs. capital-upgrade vs. shared**" trichotomy is the outdoor extension
of the VERIFY gate. The current gate has `strict` (shell-vs-contents) and `inspire`
(potential); outdoor adds a third axis: _does this render add something that would
require building works, and if so is it clearly labelled?_

- **The private outdoor spaces are the tiled ones** — the front terrace, side terrace,

  space that's already there).
- (General capability for _other_ properties: an existing private pool → restyle the pool
  area; a plot with genuine room + permits → a clearly-labelled "potential" pool. Neither
  applies to Zeniamar.)

## What this means for the pipeline (the "understanding" increase)

Today: given rooms → `understand` (frame+narration → prompt) → `render showcase` →
page. To handle a whole listing we add an understanding layer up front:

1. **Listing ingest** — accept a _folder of stills_ (not only a walkthrough video) as
   a source. Zeniamar is 31 photos, no video.

2. **Scene classify → property model (NEW, the core of this).** Claude vision (the
   art-director role) reads every photo and emits a structured **property model**:
   for each photo `{ space_type, indoor/outdoor, private/shared, quality, best_angle }`,
   then dedupes angles into **spaces with one hero each**, and flags amenities. This is
   the system _comprehending the property_ instead of being handed 4 rooms. First-pass
   output for Zeniamar is committed alongside this doc:
   `playbook/showcase/zeniamar-full.inventory.json`.

3. **Per-space understand + restage with type-specific prompts.** We have interior room
   prompts (`playbook/prompts/nano-banana/`, `playbook/prompts/styles/`). Outdoor needs
   its own set: `covered-terrace`, `roof-solarium`, `front-terrace`, `side-terrace`,
   `garden`, `pool-area`. Each keeps the honest structure/views and dresses for outdoor
   living; the solarium/garden prompts optionally emit a labelled capital-upgrade variant.

4. **Outdoor-aware VERIFY.** Add the restyle / capital-upgrade / shared trichotomy above,
   so any render that introduces a pool or structure is force-labelled, not passed off
   as existing.

5. **Showcase page grouping.** Move from a flat room list to **Inside / Outside / The
   setting**, scale to N bedrooms, and lead Outside with **both outdoor co-heroes** — the
   2nd-floor covered balcony and the 3rd-floor solarium. "Potential upgrade" renders (for
   other properties) get a distinct badge.
